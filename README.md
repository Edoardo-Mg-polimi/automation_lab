# Magnetic Levitation Control Project

Questo repository raccoglie materiali, modelli, documentazione e report relativi al progetto di laboratorio sul sistema di **magnetic levitation**.
L'obiettivo è organizzare in modo chiaro tutto il lavoro svolto, dalla documentazione tecnica iniziale fino allo sviluppo dei modelli MATLAB/Simulink e alla stesura del report finale.

## Struttura del progetto

```text
.
├── data
├── doc
├── img
├── matlab
├── paper
├── README.md
└── report
```

## Descrizione delle cartelle

### `data`
Contiene i dati raccolti dalle diverse validazioni del progetto, per esempio misure sperimentali, risultati di simulazione, file di log, esportazioni numeriche e dataset utili all'analisi del sistema.

### `doc`
Contiene i documenti forniti dal professore, come slide del corso, datasheet, manuali e altra documentazione tecnica utile per comprendere il setup sperimentale e i componenti utilizzati.

### `img`
Contiene immagini e materiale grafico, come foto del setup, screenshot di Simulink, grafici esportati, schemi a blocchi e figure da usare nel report.

### `matlab`
Contiene gli script MATLAB e i modelli Simulink del progetto. È la cartella principale per lo sviluppo del modello del sistema, la simulazione e la sintesi dei controllori.

### `paper`
Contiene paper accademici utili sul tema, usati come riferimento per la modellazione del sistema, l'analisi del comportamento dinamico e il confronto tra diverse tecniche di controllo.

### `report`
Contiene il report finale compilato in LaTeX, insieme agli eventuali file sorgenti necessari per generarlo, come capitoli, figure, bibliografia e file di configurazione.

## Obiettivo del repository

L'idea alla base di questa struttura è separare con chiarezza documentazione, codice, dati, immagini, riferimenti accademici e report finale.
In questo modo il progetto rimane ordinato, facilmente navigabile e semplice da mantenere durante tutte le fasi del lavoro.
