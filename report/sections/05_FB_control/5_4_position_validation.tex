\subsubsection{Simulation testing}

The controller is first tested in simulation on the linear model and then on the nonlinear model. 
The comparison allows us to evaluate the validity of the linear approximation and the effect of saturation.

The final controller is implemented in Simulink and tested on the physical setup. The experimental response is compared with the simulated one.

\subsubsection{Time-Domain Validation}
The time-domain validation of the position control was performed by injecting the system with a constant reference equal to the equilibrium position.
To improve the system response during the initial part, a slope limit was added to the position reference so that the reference would reach its final value in 4 seconds.
The results are shown in Figure G, H, I. 
\textcolor{red}{grafico validazioni nel tempo}

\paragraph{Neighborhood of linearized point}
Of particular interest are the tests in which the reference signal’s constant value was changed during the experiment to test the stability limits of the system. The results are shown in Figure L, M.
The worse performance on the decreasing position reference tracking is probably to attribute to the consecutive use of the hardware.
