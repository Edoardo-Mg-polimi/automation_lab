\subsubsection{Time-Domain Validation}
The time-domain validation of the position control was performed by injecting the system with a constant reference equal to the equilibrium position.
To improve the system response during the initial part, a slope limit was added to the position reference so that the reference would reach its final value in 4 seconds.
The results are shown in Figures~\ref{fig:fb_position_time_validation}, \ref{fig:fb_position_time_current}, and~\ref{fig:fb_position_time_error}.

\subsubsection{Frequency-Domain Validation}
The frequency-domain validation of the position control was done by injecting the real system with different sine wave references,
around the equilibrium position, at various frequencies.
The frequencies chosen for this validation were 1,6,20 [rad/s].
The results were then stored as data, processed and shown in the following section.  
Prior to frequency response extraction, the measured signals were filtered (using MATLAB's “filtfilt”) to remove high-frequency noise.
The cutoff frequency was selected for each test case, ensuring the fundamental sinusoidal component was preserved while suppressing noise. The cutoff frequencies used are summarized in Table X.
The filtered validations are shown in Figure C,D,E.
Using a MATLAB script, the values of Magnitude and Phase variation were extracted from the data.
This values are available in Table B. Comparing these values with the Bode Diagram of the model (Figure F),
we can see that the values are consistent.
