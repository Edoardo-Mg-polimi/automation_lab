\subsection{Position control}

The Frequency-Based Position Control was divided into two parts. 


The first part consisted in a regulator able to stabilize the unstable dynamic introduced with the linearized mechanical model.
The parameters for this regulator were identified using the Nyquist criterion and the Root Locus of the open-loop transfer function of the system.
MATLAB’s tool \textit{sisoTool} was utilized for this purpose. A set of two complex conjugate poles and complex conjugate zeros were chosen in order to easily stabilize the system while maintaining acceptable margins.
The Nyquist diagram of the stabilized system’s open-loop transfer function is:
% Diagramma di nyquist 
\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{../img/FB_validation/NYQUIST_FB_stabilizED.png}
    \caption{Nyquist diagram of the stabilized open-loop transfer function}
    \label{fig:nyquist_fb_stabilized}
\end{figure}

The second part of the control was a I regulator able to guarantee zero steady state error and reference tracking.
MATLAB’s tool \textit{pidTuner} was utilized for this purpose.
This new control loop was applied around the stabilizing control loop described in the previous section.
The control architecture based on which the two controllers were designed is

After a first draft of parameters, based on the linearized model of the system \figref{fig:control_scheme_linearized},
multiple adjustments were applied based on the non-linear model of the system \figref{fig:control_scheme_nonlinear}
response and tests on the real hardware.

    \centering

The stabilizing controller and the integral controller are
\begin{equation}
    R_{p,\mathrm{stab}}(s) = 1984\,\frac{s^2 + 105.8s + 5298}{s^2 + 400s + 4.09\times 10^4},
\end{equation}
\begin{equation}
    R_p(s) = \frac{3.0183}{s}.
\end{equation}

The margins obtained by the full system open-loop transfer function are:
\begin{itemize}
    \item Gain margin: 56.102481
    \item Phase margin: 88.431152~deg
    \item Bandwidth: 5~rad/s
\end{itemize}
