\subsection{Position control}

The frequency-based position controller was designed in two stages.
First, a stabilizing regulator was introduced for the unstable dynamics of the linearized
mechanical model. Its parameters were selected using the Nyquist criterion and the root locus of the
open-loop transfer function. MATLAB's \textit{sisoTool} was used to tune two complex-conjugate poles
and two complex-conjugate zeros while maintaining acceptable margins.
The Nyquist diagram of the stabilized system open-loop transfer function is:
% Diagramma di nyquist 
\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{../img/FB_validation/NYQUIST_FB_stabilizED.png}
    \caption{Nyquist diagram of the stabilized open-loop transfer function.}
    \label{fig:nyquist_fb_stabilized}
\end{figure}

Second, an integral regulator was added to guarantee zero steady-state error for constant references.
MATLAB's \textit{pidTuner} was used for this outer loop. The resulting control architecture is shown in
\figref{fig:control_scheme_linearized}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{../img/FB_validation/Control_Scheme_Linearized_Model.png}
    \caption{Control scheme of the linearized model.}
    \label{fig:control_scheme_linearized}
\end{figure}




After the initial linear design, the parameters were refined using the nonlinear model in
\figref{fig:control_scheme_nonlinear} and experimental tests on the real hardware.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{../img/FB_validation/Control_Scheme_Nonlinear_Model.png}
    \caption{Control scheme of the nonlinear model.}
    \label{fig:control_scheme_nonlinear}
\end{figure}



The stabilizing controller and the integral controller are
\begin{equation}
    R_{p,\mathrm{stab}}(s) = 1984\,\frac{s^2 + 105.8s + 5298}{s^2 + 400s + 4.09\times 10^4},
\end{equation}
\begin{equation}
    R_p(s) = \frac{3.0183}{s}.
\end{equation}

The margins obtained by the full system open-loop transfer function are:
\begin{itemize}
    \item Gain margin: 56.102481
    \item Phase margin: $88.431152^\circ$
    \item Bandwidth: 5~rad/s
\end{itemize}
