The equilibrium point is defined by imposing zero velocity and zero acceleration:
\begin{equation*}
    \dot{x}_1 = 0, \qquad \dot{x}_2 = 0, \qquad \dot{x}_3 = 0.
\end{equation*}

In this case there is no intertial force.
Therefore:
\begin{equation*}
    F_m = mg
\end{equation*}
with 
\begin{equation*}
    F_m = K_m \frac{i_e^2}{(l - x_e - 2r)^2}
\end{equation*}

For a selected equilibrium air gap $x_e$, the corresponding equilibrium current is
\begin{equation}
    i_e = \sqrt{\frac{m g}{K_m}} (l - x_e - 2r).
    \label{eq:equilibrium_current}
\end{equation}
As we can see $i_e$ and $x_e$ are linearly dependent. The equilibrium point is not unique, so we can select a $x_e$
as a design parameter and then compute $i_e$ from \eqref{eq:equilibrium_current}.

We select $x_e = \frac{l}{2} - r = 7$ mm. Exactely in the middle between the sensor and the electromagnet.
Then 
\begin{equation*}
\begin{aligned}
i_e 
&= \sqrt{\frac{m g}{K_m}}
\left(l - \frac{l}{2} + r - 2r\right) \\[1mm]
&= \sqrt{\frac{m g}{K_m}}
\left(\frac{l}{2} - r\right) \\[1mm]
&\simeq 0.7 \ \mathrm{A}.
\end{aligned}
\end{equation*}

Linearization point: $
\boxed{x_e = 7\ \text{mm} \qquad i_e = 0.7\ \text{A}}
$

The equilibrium command voltage is obtained from the electrical steady-state condition:
\[
   v_e = u_e = \frac{R}{K_g} i_e \simeq 6.614\ \text{V}.
\]

In the implemented controllers, it is important to distinguish absolute variables from deviation variables:
\begin{equation*}
    \Delta x = x - x_e, \qquad \Delta i = i - i_e, \qquad \Delta u = u - u_e.
\end{equation*}


\subsubsection{Linearization}
The nonlinear model is linearized around the equilibrium point $\left(x_e,0,i_e,u_e\right)$. Using deviation variables, the linearized model is

The design uses deviation variables around the equilibrium point. With the closed current loop bandwidth $\omega_i$, the extended state is
\begin{equation*}
    \vect{x} = \begin{bmatrix} \Delta x & \Delta \dot{x} & \Delta i \end{bmatrix}^T,
\end{equation*}
the input is $\Delta i_{ref}$, and the measured outputs are $\Delta x$ and $\Delta i$.

\textcolor{red}{ALL THE LINEARIZATION CALCULUS}


Defining
\[
    k_1 = \frac{2 K_m i_e^2}{m (l - 2 r - x_e)^3} \simeq 2802.857
    \qquad
    k_2 = \frac{2 K_m i_e}{m (l - 2 r - x_e)^2} \simeq 27.732
\]


The model is
\begin{equation}
    \dot{\vect{x}} = A \vect{x} + B \Delta i_{ref},
\end{equation}
with
\begin{equation}
    A =
    \begin{bmatrix}
        0 & 1 & 0 \\
        k_1 & 0 & k_2 \\
        0 & 0 & -\omega_i
    \end{bmatrix},
    \qquad
    B =
    \begin{bmatrix}
        0 \\
        0 \\
        \omega_i
    \end{bmatrix}.
\end{equation}

The measured outputs are collected as
\begin{equation}
    C =
    \begin{bmatrix}
        1 & 0 & 0 \\
        0 & 0 & 1
    \end{bmatrix},
    \qquad
    D = 0.
\end{equation}
