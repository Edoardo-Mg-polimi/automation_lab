The equilibrium point is defined by imposing zero velocity and zero acceleration:
\begin{equation*}
    \dot{x}_1 = 0, \qquad \dot{x}_2 = 0, \qquad \dot{x}_3 = 0.
\end{equation*}

In this case there is no intertial force.
Therefore:
\begin{equation*}
    F_m = mg
\end{equation*}
with 
\begin{equation*}
    F_m = K_m \frac{i_e^2}{(l - x_e - 2r)^2}
\end{equation*}

For a selected equilibrium air gap $x_e$, the corresponding equilibrium current is
\begin{equation}
    i_e = \sqrt{\frac{m g}{K_m}} (l - x_e - 2r).
    \label{eq:equilibrium_current}
\end{equation}
As we can see $i_e$ and $x_e$ are linearly dependent. The equilibrium point is not unique, so we can select a $x_e$
as a design parameter and then compute $i_e$ from \eqref{eq:equilibrium_current}.

We select $x_e = \frac{l}{2} - r = 7$ mm. Exactely in the middle between the sensor and the electromagnet.
Then 
\begin{equation*}
\begin{aligned}
i_e 
&= \sqrt{\frac{m g}{K_m}}
\left(l - \frac{l}{2} + r - 2r\right) \\[1mm]
&= \sqrt{\frac{m g}{K_m}}
\left(\frac{l}{2} - r\right) \\[1mm]
&\simeq 0.7 \ \mathrm{A}.
\end{aligned}
\end{equation*}

Linearization point: $
\boxed{x_e = 7\ \text{mm} \qquad i_e = 0.7\ \text{A}}
$

The equilibrium command voltage is obtained from the electrical steady-state condition:
\[
   v_e = u_e = \frac{R}{K_g} i_e \simeq 6.614\ \text{V}.
\]

In the implemented controllers, it is important to distinguish absolute variables from deviation variables:
\begin{equation*}
    \Delta x = x - x_e, \qquad \Delta i = i - i_e, \qquad \Delta u = u - u_e.
\end{equation*}

\subsubsection{Linearization}
The coplete model is
\[
\begin{cases}
    \dot{x}_1 = x_2 \\[2mm]
    \dot{x}_2 = g - \dfrac{K_m}{m}\dfrac{x_3^2}{d^2} \\[2mm]
    \dot{x}_3 = -\dfrac{R}{L}x_3 + \dfrac{K_g}{L}u \\[2mm]
    y = x_1
\end{cases}
\]
Only the second equation is nonlinear, so we linearize it around the equilibrium point.
The first and third equations are already linear, so they are not affected by the linearization process.

The nonlinear acceleration equation is
\[
\dot{x}_2 =
f(x_1,x_3)
=
\frac{K_m}{m}
\frac{x_3^2}
{\left(l-2r-x_1\right)^2}
-g.
\]

The system is linearized around the equilibrium point

\begin{equation}
\bar{x}=
\begin{bmatrix}
x_e &
0 &
i_e
\end{bmatrix}^{T}.
\end{equation}

Using a first-order Taylor expansion,

\begin{equation}
\delta\dot{x}_2
=
\left.\frac{\partial f}{\partial x_1}\right|_{\bar{x}}
\delta x_1
+
\left.\frac{\partial f}{\partial x_3}\right|_{\bar{x}}
\delta x_3 ,
\end{equation}

where

\begin{equation}
\delta x_i = x_i-\bar{x}_i.
\end{equation}

The partial derivatives are

\begin{equation}
\frac{\partial f}{\partial x_1}
=
\frac{2K_m x_3^2}
{m\left(l-2r-x_1\right)^3},
\end{equation}

and

\begin{equation}
\frac{\partial f}{\partial x_3}
=
\frac{2K_m x_3}
{m\left(l-2r-x_1\right)^2}.
\end{equation}

Evaluating them at the equilibrium point gives

\begin{equation}
A_{21}
=
\left.\frac{\partial f}{\partial x_1}\right|_{\bar{x}}
=
\frac{2K_m \bar{x}_3^{\,2}}
{m\left(l-2r-\bar{x}_1\right)^3},
\end{equation}

\begin{equation}
A_{23}
=
\left.\frac{\partial f}{\partial x_3}\right|_{\bar{x}}
=
\frac{2K_m \bar{x}_3}
{m\left(l-2r-\bar{x}_1\right)^2}.
\end{equation}

Therefore, the linearized mechanical dynamics become

\begin{equation}
\delta\dot{x}_2
=
A_{21}\,\delta x_1
+
A_{23}\,\delta x_3.
\end{equation}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
Defining
\[
    k_1 = \frac{2 K_m i_e^2}{m (l - 2 r - x_e)^3} \simeq 2802.857
    \qquad
    k_2 = \frac{2 K_m i_e}{m (l - 2 r - x_e)^2} \simeq 27.732
\]

The complete model is:
\begin{equation}
    \dot{\vect{x}} = A \vect{x} + B \Delta i_{ref},
\end{equation}
with
\begin{equation}
    A =
    \begin{bmatrix}
        0 & 1 & 0 \\
        k_1 & 0 & k_2 \\
        0 & 0 & -\omega_i
    \end{bmatrix},
    \qquad
    B =
    \begin{bmatrix}
        0 \\
        0 \\
        \omega_i
    \end{bmatrix}.
\end{equation}

The measured outputs are collected as
\begin{equation}
    C =
    \begin{bmatrix}
        1 & 0 & 0 \\
        0 & 0 & 1
    \end{bmatrix},
    \qquad
    D = 0.
\end{equation}
