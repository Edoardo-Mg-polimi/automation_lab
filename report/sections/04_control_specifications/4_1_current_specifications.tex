\subsection{Current loop specifications}
The electrical subsystem is open-loop stable, so the current controller is mainly required to provide
fast tracking of the current reference while avoiding actuator saturation.
\begin{itemize}
    \item adequate phase margin $\phi_m$;
    \item high bandwidth with respect to the electrical pole, $\omega_c \gg \omega_i$;
    \item limited control action, $|v_c(t)| \leq V_{max}$.
\end{itemize}
