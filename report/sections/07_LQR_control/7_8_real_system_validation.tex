\subsection{Real system implementation and validation}
The LQR controller with integral action is implemented in Simulink and tested on the physical setup.
The experimental tuning is not identical to the simulation tuning. The controller that gives the best
response in simulation is too aggressive for the real system, while the tuning used on the real setup is
chosen to account for sensor noise, actuator saturation and model uncertainty. Therefore the simulation
parameters and the experimental parameters must be interpreted as two different tunings of the same
control architecture.

\subsubsection{Frequency-Domain Validation}

The frequency-domain validation is performed with sinusoidal references at
\begin{equation}
    \omega = 1,\ 6,\ 15\ \mathrm{rad/s}.
\end{equation}
The experimental tuning used for these tests is
\begin{equation}
    Q_{aug,exp}
    =
    \mathrm{diag}
    \left(
        5000,\;
        25,\;
        10^{-9},\;
        5\times10^{-4}
    \right),
    \qquad
    R_{aug,exp} = 0.09.
\end{equation}
The measured sinusoidal response is compared with the predicted frequency response in terms of
attenuation and phase shift.
