\subsection{Simulation}

Simulation is performed only for the LQR controller with integral action, using both the linear and
nonlinear Simulink models.

The nominal simulation tuning is
\begin{equation}
    Q_{aug,sim}
    =
    \mathrm{diag}
    \left(
        5000,\;
        5\times10^{-1},\;
        10^{-9},\;
        9\times10^{4}
    \right),
    \qquad
    R_{aug,sim} = 5\times10^{-4}.
\end{equation}

This tuning works in simulation but not on the real setup. The real system needs a different tuning due
to noise, nonlinearities, current saturation and calibration errors.

\paragraph{Stability margins}

The stability margins were evaluated on the open-loop transfer function associated with the
state-feedback law, not on the closed-loop transfer function $H_x(s)$. Since MATLAB's
\texttt{margin} command assumes negative feedback, the loop function is written without
the minus sign of the control law:
\begin{equation}
    L_{lqi}(s) =
    K_{aug}\left(sI-A_{aug}\right)^{-1}B_{aug},
\end{equation}
where the closed-loop transfer function from the position reference to the position output is denoted
as $H_x(s)$.
