\subsection{Simulation}

Simulation is performed only for the LQR controller with integral action, using both the linear and
nonlinear Simulink models.

The nominal simulation tuning is
\begin{equation}
    Q_{aug,sim}
    =
    \mathrm{diag}
    \left(
        5000,\;
        5\times10^{-1},\;
        10^{-9},\;
        9\times10^{4}
    \right),
    \qquad
    R_{aug,sim} = 5\times10^{-4}.
\end{equation}

This tuning works in simulation but not on the real setup. The real system needs a different tuning due
to noise, nonlinearities, current saturation and calibration errors.
